# 🔐 Play Console - Test Credentials Guide

## 📋 **WHAT GOOGLE NEEDS**

Google Play needs test credentials to:
- Test your app on different devices
- Verify the app works correctly
- Check compatibility

**This is safe!** Google only uses these credentials for testing, not for anything else.

---

## ✅ **STEP 1: CREATE A TEST ACCOUNT (If You Don't Have One)**

### **Option A: Use Your Existing Account**
- If you already have a test account, use that
- Make sure it's not your personal account (create a separate one)

### **Option B: Create a New Test Account**
1. **Open your FinWise app**
2. **Go to Sign Up**
3. **Create a test account:**
   - Email: `test.finwise@gmail.com` (or any test email)
   - Password: `Test123456!` (or any secure password)
   - Name: `Test User`
4. **Log in once** to make sure it works
5. **Add some test data** (optional):
   - Add a few transactions
   - Create a goal
   - Set a budget

### **Instruction 2: Account Creation (If Needed)**

**Title:** `Account Creation`

**Instructions:**
```
If you need to create an account:
1. Tap "Sign Up" or "Create Account"
2. Enter email address
3. Enter password (minimum 6 characters)
4. Enter name (optional)
5. Tap "Create Account"
6. Account will be created and you'll be logged in automatically
```

### **Check the box:**
☑ **"Allow Android to use the credentials you provide for performance and app compatibility testing"**

**Click "Add instruction"** and enter:

**Instruction 1:**
- **Title:** `Login to FinWise`
- **Instructions:**
```
1. Launch the FinWise app
2. Tap "Login" button on the welcome screen
3. Enter email: test.finwise@gmail.com
4. Enter password: Test123456!
5. Tap "Login"
6. You will see the home screen with financial dashboard, transactions, and goals
```

**Instruction 2 (Optional - if you want to show account creation):**
- **Title:** `Create Account`
- **Instructions:**
```
To create a new account:
1. Tap "Sign Up" on the welcome screen
2. Enter a valid email address

```
