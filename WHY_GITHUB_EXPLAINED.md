# 🤔 What is GitHub and Why Do You Need It?

## 📚 **What is GitHub?**

**GitHub** is like a **cloud storage for your code** - similar to Google Drive, but specifically designed for software projects.

Think of it as:
- 📦 **Backup**: Your code is saved online (never lose it!)
- 👥 **Collaboration**: Others can see and help with your code
- 📝 **History**: See every change you made (like "undo" for your entire project)
- 🌐 **Showcase**: Show your work to employers, clients, or the world
- 🔄 **Sync**: Access your code from any computer

## 🚀 **How to Use It:**

### **1. Push Your Code (First Time):**
```bash
cd C:\FinWiseApp\finewise
git init
git add .
git commit -m "Initial commit: FinWise app"
git remote add origin https://github.com/YVES10BOBO/FinWise.git
git branch -M main
git push -u origin main
```

### **2. Update Code (Later):**
```bash
git add .
git commit -m "Description of changes"
git push
```

### **3. Enable GitHub Pages:**
1. Go to: https://github.com/YVES10BOBO/FinWise
2. Settings → Pages
3. Source: `main` branch, `/ (root)`
4. Save
5. Your privacy policy: `https://yves10bobo.github.io/FinWise/`
