## 🎨 **Feature Graphic (1024x500px Banner)**

### **Status: NOT CREATED YET - You Need to Create This**

### **What is Feature Graphic?**
- Banner image shown at top of Play Store listing
- First thing users see
- Should be eye-catching and show app name + key features

### **How to Create Feature Graphic:**

#### **Option 1: Use Canva (Free & Easy)**

1. **Go to Canva:** https://www.canva.com
2. **Create custom size:** 1024 x 500 pixels
3. **Design elements:**
   - App name: "FinWise" (large, bold)
   - Tagline: "Your Personal Finance Manager"
   - Key features (icons + text):
     - 💰 Track Expenses
     - 📊 Manage Budget
     - 🎯 Set Goals
   - App icon (if you want)
   - Gradient background (matching your app colors)

4. **Colors to use:**
   - Primary: Your app's primary color (from theme)
   - White text
   - Clean, modern design

5. **Download as PNG**

#### **Option 2: Use Figma (Free)**

1. **Go to Figma:** https://www.figma.com
2. **Create frame:** 1024 x 500
3. **Design similar to Canva**
4. **Export as PNG**

#### **Option 3: Use PowerPoint/Google Slides**

1. **Create slide:** 1024 x 500 pixels
2. **Add text and images**
3. **Export as PNG**

## 🎯 **Quick Steps to Take Screenshots**

### **Step 1: Prepare Your App**
1. Make sure app is working
2. Add some sample data:
   - Add 5-10 transactions
   - Create 2-3 goals
   - Add transactions in different categories
   - Make sure you have both income and expenses

### **Step 2: Take Screenshots**
1. **On Android Phone:**
   - Press Volume Down + Power button simultaneously
   - Screenshots saved in Gallery

2. **On Android Emulator:**
   - Click camera icon in toolbar
   - Or use screenshot tool

3. **On iOS (if testing):**
   - Press Volume Up + Power button

### **Step 3: Edit Screenshots (Optional)**
- Crop if needed
- Add text labels (optional)
- Ensure good quality

### **Step 4: Organize**
- Name files: `screenshot1.png`, `screenshot2.png`, etc.
- Keep them organized in a folder

---

## 💡 **Tips for Great Screenshots**

1. **Show Real Data:**
   - Don't use empty states
   - Add sample transactions
   - Show actual features working

2. **Clean Screens:**
   - Remove any debug info
   - Hide status bar if needed
   - Clean, professional look

3. **Highlight Features:**
   - Show key features clearly
   - Make important elements visible
   - Good contrast

4. **Consistent Style:**
   - All screenshots should match
   - Same theme (light or dark)
   - Professional appearance

## 📱 **Screenshot Specifications**

### **Requirements:**
- **Format:** PNG or JPEG
- **Size:** Minimum 320px, Maximum 3840px
- **Aspect Ratio:** 16:9 or 9:16 (portrait recommended)
- **File Size:** Maximum 8MB per image
- **Minimum:** 2 screenshots
- **Recommended:** 4-8 screenshots

### **Best Practices:**
- Use portrait orientation (9:16)
- Resolution: 1080x1920px (Full HD)
- Show different features in each screenshot
- Don't repeat same screen
