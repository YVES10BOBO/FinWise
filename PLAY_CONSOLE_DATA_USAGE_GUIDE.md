## 📝 **QUICK SUMMARY FOR ALL:**

For **EVERY** data type, select:

1. **Is this data collected?** → ☑ **Yes**
2. **How is this data collected?** → ☑ **App functionality** (and **Analytics** for App activity)
3. **How is this data used?** → ☑ **App functionality** (and **Personalization** for Financial info)
4. **Is this data shared?** → ☑ **Yes**
5. **Who is this data shared with?** → ☑ **Service providers** → Enter "Firebase (Google)" details
6. **Is this data encrypted?** → ☑ **Yes**
7. **Can users request deletion?** → ☑ **Yes**
