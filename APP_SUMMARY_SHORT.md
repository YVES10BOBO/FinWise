# FinWise - Quick Summary

## What is FinWise?
A personal finance app for Rwanda that helps you track expenses, manage budgets, and achieve financial goals.

---

## Problems It Solves:

### Problem 1: "I don't know where my money goes"
**Solution:** Easy expense tracking - Add transactions in seconds, see complete spending history

### Problem 2: "I can't stick to my budget"  
**Solution:** Smart budgets - Set budgets per category, see visual progress bars, get alerts when overspending

### Problem 3: "I can't save money"
**Solution:** Goal tracking - Set savings goals, track progress with visual indicators

### Problem 4: "I don't understand my finances"
**Solution:** Financial dashboard - See balance, income, expenses, savings rate, and health score at a glance

### Problem 5: "Managing money is complicated"
**Solution:** All-in-one app - Track, budget, goals, analytics - everything in one place

---

## Key Features:

✅ **Dashboard** - Balance, income, expenses, savings rate, financial health score  
✅ **Transactions** - Add income/expenses, 20+ categories, search & filter  
✅ **Budgets** - Category budgets with visual progress bars and recommendations  
✅ **Goals** - Set savings goals and track progress  
✅ **Analytics** - Charts showing spending patterns  
✅ **Mobile Money** - Track Mobile Money transactions  
✅ **RWF Currency** - All amounts in Rwandan Francs  
✅ **Privacy** - Data stays on your device, no cloud storage  

---

## Who Should Use It?

Anyone who wants to:
- Track where their money goes
- Stick to a budget
- Save money for goals
- Understand their finances better

---

## Quick Summary:
**FinWise helps people track expenses, manage budgets, and achieve financial goals. It solves the problem of not knowing where money goes by providing an easy way to record transactions, set budgets, and see spending patterns - all in one simple app.**
