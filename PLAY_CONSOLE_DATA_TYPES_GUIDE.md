# 📋 Play Console - Data Types Selection Guide

## 🎯 **STEP 3: DATA TYPES**

Select **ONLY** the data types that FinWise actually collects. Here's what to select:

---

## ✅ **SELECT THESE:**

### **1. Personal info** (Click to expand)
- ☑ **Email address** (Required - for account creation/login)
- ☑ **Name** (Optional - if user provides it during signup)
- ☑ **User IDs** (Firebase User ID - automatically generated)

**Total: 3 data types selected**

---

### **2. Financial info** (Click to expand)
- ☑ **Other financial info** (Select this)
  - When asked for details, enter: "Expense transactions, income information, budget data, financial goals, spending categories"

**Total: 1 data type selected**

---

### **3. Photos and videos** (Click to expand)
- ☑ **Photos** (Optional - if user uploads profile picture)
  - When asked for details, enter: "Profile pictures uploaded by users"

**Total: 1 data type selected**

---

### **4. App activity** (Click to expand)
- ☑ **App interactions** (Optional - for analytics/improvement)
  - When asked for details, enter: "Features accessed, time spent in app, user interactions"

**Total: 1 data type selected**

---

### **5. Device or other IDs** (Click to expand)
- ☑ **Device or other IDs** (Optional - for app functionality)
  - When asked for details, enter: "Device identifiers for app functionality and Firebase services"

**Total: 1 data type selected**

---

## ❌ **DO NOT SELECT:**

- **Location** - FinWise doesn't collect location data
- **Health and fitness** - Not applicable
- **Messages** - Not applicable
- **Audio files** - Not applicable
- **Files and docs** - Not applicable
- **Calendar** - Not applicable
- **Contacts** - Not applicable
- **Web browsing** - Not applicable
- **App info and performance** - Only if you're using crash reporting (optional)

---

## 📝 **STEP-BY-STEP:**

1. **Click "Personal info"** → Select:
   - ☑ Email address
   - ☑ Name
   - ☑ User IDs

2. **Click "Financial info"** → Select:
   - ☑ Other financial info
   - Enter details: "Expense transactions, income information, budget data, financial goals"

3. **Click "Photos and videos"** → Select:
   - ☑ Photos
   - Enter details: "Profile pictures uploaded by users"

4. **Click "App activity"** → Select:
   - ☑ App interactions
   - Enter details: "Features accessed, time spent in app"

5. **Click "Device or other IDs"** → Select:
   - ☑ Device or other IDs
   - Enter details: "Device identifiers for app functionality"

6. **Click "Next"** to continue
